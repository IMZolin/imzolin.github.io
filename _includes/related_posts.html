{%- comment -%} Related articles box. A post is related when - one post links to the other (a mention, e.g. via post_url), or - the two posts share at least one tag. Mentions rank first, then posts with more shared tags, then newer posts. Opt out per post with `related_posts: false`. {%- endcomment -%} {%- assign this_slug = page.name | remove: '.md' | remove: '.markdown' -%} {%- assign mention_list = '' | split: '' -%} {%- assign tag_list = '' | split: '' -%} {%- assign shown = '' -%} {%- for other in site.posts -%} {%- if other.url == page.url -%}{%- continue -%}{%- endif -%} {%- assign other_slug = other.name | remove: '.md' | remove: '.markdown' -%} {%- assign mentioned = false -%} {%- if other.content contains page.url or other.content contains this_slug -%}{%- assign mentioned = true -%}{%- endif -%} {%- if page.content contains other.url or page.content contains other_slug -%}{%- assign mentioned = true -%}{%- endif -%} {%- assign shared = '' -%} {%- for tag in page.tags -%} {%- if other.tags contains tag -%}{%- assign shared = shared | append: tag | append: ', ' -%}{%- endif -%} {%- endfor -%} {%- if mentioned -%} {%- assign mention_list = mention_list | push: other -%} {%- elsif shared != '' -%} {%- assign tag_list = tag_list | push: other -%} {%- endif -%} {%- endfor -%} {%- assign related = mention_list | concat: tag_list -%} {%- if related.size > 0 -%}
